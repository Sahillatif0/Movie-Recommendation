# Graph-Based Movie Recommendation System (ML-100K)

A Flask web app that builds a bipartite user–movie graph from the MovieLens 100K dataset, runs link-prediction algorithms (Jaccard, Adamic/Adar, Resource Allocation), and serves an interactive PyVis graph, adjacency matrix + heatmap, and on-demand movie recommendations.

## Dataset
- **MovieLens 100K** (`u.data`, `u.item`)
- 100,000 ratings from 943 users on 1,682 movies
- Data is downloaded automatically into `data/ml-100k/`

## Features
- Randomly samples 10 users on each app run for a fresh graph
- Bipartite NetworkX graph with user?movie rating edges
- PyVis interactive visualization saved to `templates/graph.html`
- Adjacency matrix pivot + matplotlib heatmap
- Link prediction algorithms: Jaccard, Adamic/Adar, Resource Allocation
- Web dashboard with routes for graph, matrix, and recommendations

## How it works
1. `data_loader.py` loads `u.data` and `u.item`, merges movie titles.
2. `graph_model.py` samples 10 users, builds a bipartite graph, and exposes link-prediction helpers plus PyVis export and heatmap generation.
3. `app.py` wires Flask routes: `/` (home), `/graph` (generate + show PyVis), `/matrix` (matrix + heatmap + CSV download), `/recommend` (form + results).
4. `static/` holds styling, JS interactions, and generated `heatmap.png`; `templates/` contains the HTML views.

## Algorithms
- **Jaccard Coefficient**: overlap of neighbors between user and movie nodes
- **Adamic/Adar**: penalizes high-degree neighbors for more specific overlap
- **Resource Allocation Index**: similar to Adamic/Adar with degree weighting
