# Graph-Based Movie Recommendation System (ML-100K)

A Flask web app that builds a bipartite user-movie graph from the MovieLens 100K dataset, runs several link-prediction and collaborative algorithms, and serves modern graph, matrix, and recommendation experiences powered by PyVis + NetworkX.

## Dataset
- **MovieLens 100K** (`u.data`, `u.item`)
- 100,000 ratings from 943 users on 1,682 movies
- Data is downloaded automatically into `data/ml-100k/`

## Features
**Graph exploration**
- Randomly samples 20 users per refresh with controls to reshuffle or lock the sample.
- PyVis-powered bipartite visualization (users vs movies) with a modern loader overlay and quick link to the adjacency matrix.
- Dedicated adjacency matrix page plus CSV download and autogenerated heatmap.

**Recommendation studio**
- Run up to four algorithms side-by-side for any user; each algorithm gets its own result card.
- Optional blend slider combines the primary algorithm with the others (0-100 weight) for hybrid rankings.
- Top-N selector (4-40) lets you decide how many recommendations to compute/export.
- Quick link to download the recommendation matrix for the chosen configuration.

**Recommendation graph mode**
- `/graph?mode=recommendations&user_id=42&algorithm=cosine` renders a PyVis graph with the selected user and only their recommended movies (no loader overlay for instant visibility).

**Quality-of-life additions**
- Sticky navbar with shortcuts to all views, plus a REST endpoint (`/api/node/<id>`) for node metadata.
- Refined styling (custom fonts, cards, gradients) and lightweight JS helpers in `static/js/script.js`.

## How it works
1. `data_loader.py` loads `u.data` and `u.item`, merges movie titles.
2. `graph_model.py` samples 20 users by default, builds a bipartite graph, and exposes link-prediction helpers plus PyVis export and heatmap generation.
3. `app.py` wires Flask routes: `/` (home), `/graph` (generate + show PyVis), `/matrix` (matrix + heatmap + CSV download), `/recommend` (form + results).
4. `static/` holds styling, JS interactions, and generated `heatmap.png`; `templates/` contains the HTML views.

## Algorithm suite
- **Cosine collaborative filtering**: user-based similarity via mean-centered rating vectors (default).
- **Jaccard / Adamic-Adar / Resource Allocation**: set-similarity metrics based on shared watchers.
- **Preferential Attachment**: high-degree bias scored on overlap mass.
- **Personalized PageRank**: random-walk prominence seeded on the selected user.

Blend mode normalizes every algorithm to 0-5 before combining, so mixed lists stay comparable.
